## Micro-interaction findings

1. **Toast stack behavior.** Two toasts ("Prompt copied to clipboard", "Copied issue link to clipboard") stack bottom-right, newest above, each with its own ✕. They survive route changes (issue detail → issue list) and dismiss independently on their own timers with a fade — the older-created one fades first (f_0072–f_0074), giving a staggered collapse rather than a group dismissal. Total observed lifetime ~6–7 s.
2. **Empty-block editor placeholder.** Clicking empty space under the description checklist creates a block whose placeholder is "Type `/` for commands…" with the slash rendered as a keycap chip; the block silently disappears when focus leaves with no content.
3. **Issue-toolbar overflow menu.** The chevron at the end of the issue toolbar opens a compact right-aligned dropdown with "Copy as prompt ⌘⌥P" (shortcut right-aligned) and "Configure coding tools…". Dismisses on click-away, leaving no toolbar active state.
4. **Swipe-back navigation indicator.** Between issue detail and issue list a large gray left-arrow overlay slides over the sidebar — the macOS/browser trackpad swipe-back affordance — confirming back-gesture navigation rather than breadcrumb click.
5. **List-row affordances.** In the grouped list ("In Progress 1" header with per-group + button), a leading selection checkbox and ⋯ menu appear transiently on the row (hover/selection remnant), and hovering the title shows the canonical issue URL in the browser status bar (rows are real links).
6. **Insights panel, two stages.** First click docks a slim right panel with pill tabs (Assignees/Labels/Priority/Projects) and per-facet counts ("No assignee 1"); full report mode shows a dismissible intro banner (Examples / Documentation links), a chart configurator with three selects — Measure (Issue count), Slice (Status), Segment (Priority) — an async "Loading…" state that resolves into a 1-bar column chart with dashed gridlines and axis labels 0/1, plus a data table (Status / Issue count / No priority), expand + settings + ⋯ chart actions, and a persistent footer link "Set default for everyone". Dismissing the banner reflows the panel upward (f_0098).
7. **Filter menu.** The funnel icon opens an "Add Filter…" menu carrying keyboard hint `F` and 19 entries incl. AI filter, Advanced filter, Agent, Agent Session, Suggested label, Auto-closed, Content, Template — each with a chevron for a submenu. Click-away dismisses without applying anything.
8. **Display options popover — mode-aware vocabulary.** A single popover with a List/Board segmented toggle re-labels its rows on switch: List → Grouping/Sub-grouping/Ordering + "List options" (Nested sub-issues, Show empty groups); Board → Columns/Rows/Ordering + "Board options" (Show empty columns). Shared: Order completed by recency, Completed issues (All), Show sub-issues (on), and a "Display properties" chip-toggle grid (active chips solid: ID, Status, Assignee, Priority, Project, Due date, Labels, Created; inactive dim: Milestone, Release, Links, Time in status, Updated). After deviating from defaults the footer gains **Reset** + **Set default for everyone**, and the toolbar sliders icon acquires a small **blue dot badge**.
9. **Board rendering with hidden empty columns.** With "Show empty columns" off, only populated columns render (In Progress 1); all empty statuses collapse into a right-hand "Hidden columns" section — one row per status with its status icon and count 0 (Backlog dashed circle, Todo hollow, Done blue check, Canceled ✕, Duplicate check). The view switch is instant (no animation captured between f_0085→f_0086).
10. **Card anatomy & hover.** Card shows ID (muted), status-dot + title, a ⋯ actions stub, "Created Aug 24" footer (Created is an enabled display property) and an assignee-placeholder icon. Hovering the column/card reveals a full-width "+" quick-add pill at the column bottom.
11. **Card drag physics.** Mouse-down + move lifts the card to a floating layer that tracks the cursor with a grab-hand cursor; the origin slot renders as an empty placeholder keeping column height. Dropping outside any valid column (open canvas — the only other columns are hidden) snap-returns the card to its origin with no status change, no toast, no undo bar. Performed twice (f_0105–0108, f_0109–0111).
12. **Card click vs drag disambiguation.** A plain click on the card (f_0101→f_0102) navigates to the issue detail route (real link, URL in status bar); drag only begins after a movement threshold.
13. **New issue modal from a board column.** The column "+" opens the centered "New issue" dialog pre-seeded with that column's status chip (In Progress). Anatomy: team chip breadcrumb (TRENDZO > New issue), expand-to-full and close buttons, title + description placeholders, property chips (Priority, Assignee, Project, Labels, ⋯ overflow), attachment icon, "Create more" toggle, primary "Create issue".
14. **"Save as draft" is content-reactive.** The header "Save as draft" button does not exist in a pristine modal; it appears on the first typed character and vanishes when the title is cleared (select-all + delete), so closing an emptied modal shows no discard/draft confirmation.
15. **Persistent view state.** The board/display changes, the Insights report, and the badge on the display-options icon all persist across the modal open/close and through the end of the capture.
