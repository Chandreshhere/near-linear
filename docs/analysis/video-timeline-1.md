## Micro-interaction findings

1. **Sidebar hover + URL preview**: every sidebar item shows a rounded hover pill; the browser status line (bottom-left) previews the destination URL on hover — how each hover target was identified. Active nav item keeps a filled selection pill distinct from the lighter hover tint.
2. **Shortcut-hint tooltip**: sustained hover on "My issues" pops a tooltip "Go to my issues" with boxed keycaps "G then M" — Linear surfaces its go-to chord (G,M) contextually. Same pattern later: "Copy as prompt ⌘ ⌥ P" tooltip on the icon button, and keycaps embedded in empty-state copy ("⌥ V" in Views) and inside buttons ("Create new issue [C]").
3. **"More" popover**: clicking More opens a click-anchored popover (Members / Releases / Teams / divider / Customize sidebar) overlapping the team list; rows highlight on hover; dismissed by click-away with no route change.
4. **Row hover affordances in tables/lists**: project rows and issue rows reveal a leading multi-select checkbox and (issues) a `…` overflow only on hover; entire row tints. Group headers ("Backlog 1") expose a right-aligned "+" quick-add on the group.
5. **Projects table anatomy**: milestone chips ("◇ M3 · Delivery flow (handover → deliver → proof)") with a date suffix; Health "No updates" dashed circles; overdue target dates rendered red including red calendar glyph (Aug 21st, Aug 11th); Status as 0% progress rings; Lead avatars. Right rail is a segmented insights panel (Health/Teams/Leads) whose Health counts and row order differ between workspace scope (No update expected 5 / Update missing 5) and team scope (Update missing 3 first, then No update expected 2).
6. **Empty states are view-specific**: My issues (isometric disc + "Create new issue"), Views (layers + save-view tip with ⌥V), Loops (knot + agent-automation copy + "Docs and Examples"), PGME All issues (status-icon cluster + "Create new issue [C]" + Documentation). Each pairs one indigo primary with one neutral secondary button.
7. **Agent onboarding**: The Agent "New chat" screen shows the Ask Linear composer (Skills dropdown, attach, send) alone at first (f0001) and later with a dismissible "Get started with some examples" 3-card row (Create a new project / Research a topic / Create automated loop) — the composer shifts up to make room; the panel has its own X.
8. **Route-transition capture**: f0015 catches the click-to-navigate gap — sidebar selection pill already moved to Projects while the old Agent content is still rendered (~≤250ms stale content window).
9. **Issue detail anatomy**: full-route issue page (not a modal): breadcrumb w/ favorite star and overflow, checkbox-list description, emoji/attach row, "+ Add sub-issues", Activity feed with created/moved entries and timestamps, Subscribe + subscriber avatars, comment composer, right Properties rail (status, priority, assignee, Labels, Project) and a 5-icon copy cluster (link / ID / git branch / copy-as-prompt / ⌄ menu).
10. **Copy-as-prompt & coding-tools menu**: the ⌄ next to the copy-as-prompt icon opens a two-item menu — "Copy as prompt ⌘⌥P" and "Configure coding tools…" — an AI/agent-oriented export of the issue as an LLM prompt. Clicking the main icon fires the copy directly.
11. **Toast behavior**: toasts appear bottom-right as dark pills with a leading clipboard icon and trailing X; a second toast stacks below the first, pushing the older one up; they are long-lived (visible ≥6s, still present at f0066) and individually dismissible — no auto-dismiss observed within this half.
